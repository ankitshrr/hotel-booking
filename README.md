# Room Manager Pro - Calendar View

A dynamic, premium web application for managing hotel room bookings. Features a calendar view, room filtering, guest search, and Excel import/export functionality.

## Features
- Interactive Calendar View for bookings
- Dashboard for quick statistics
- Room filtering by type (AC, Fan, Shared/Private Bath)
- Excel file Import and Export
- Built-in Calculator
- Glassmorphism design and dark mode styling

## Tech Stack
- HTML5
- CSS3 (Custom styling, modern layout)
- JavaScript (Vanilla JS for logic and DOM manipulation)
